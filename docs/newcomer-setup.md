# 새이웃 신청 페이지 — 설치 가이드

`/newcomer` 페이지는 신청 내용을 구글 시트로 보냅니다. 처음 한 번만 아래 순서대로 설정하면 됩니다. 약 15분 걸립니다.

> **권장:** 개인 계정 대신 **교회 공용 구글 계정**으로 시트를 만드세요. 담당자가 바뀌어도 데이터와 알림이 유지됩니다.

---

## 1. 시트와 스크립트 만들기

1. 교회 공용 구글 계정으로 [sheets.new](https://sheets.new)에 들어가 새 시트를 만들고, 이름을 `새이웃 신청`처럼 붙입니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 `Code.gs` 내용을 모두 지우고, 레포의 [`apps-script/Code.gs`](../apps-script/Code.gs)를 그대로 붙여 넣은 뒤 저장(💾)합니다.

## 2. 알림 이메일 설정

1. 왼쪽 ⚙️ **프로젝트 설정** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**를 누릅니다.
2. `NOTIFY_EMAIL` = 알림을 받을 이메일을 입력합니다. 여러 명이면 쉼표로 구분합니다(`a@x.com,b@y.com`).
3. **스크립트 속성 저장**을 누릅니다.

## 3. 최초 설정 실행

1. 편집기 상단의 함수 선택 칸에서 `setup`을 고르고 **▶ 실행**을 누릅니다.
2. 권한 요청 창이 뜨면 **권한 검토 → 계정 선택**을 누릅니다. "확인되지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다.
   교회 계정이 직접 만든 스크립트라 나오는 정상적인 경고입니다.
3. 실행이 끝나면 시트에 `새이웃 신청` 탭이 생깁니다. 머리글, 진행 상태 드롭다운, 매일 새벽 4시 파기 트리거도 함께 만들어집니다.
4. (선택) `testNotify`를 실행해 알림 메일이 오는지 확인합니다.

## 4. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(⚙️)에서 **웹 앱**을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 5. 페이지에 URL 넣기

`newcomer/index.html` 아래쪽 `<script>`의 다음 줄에 복사한 URL을 넣고 커밋합니다.

```js
const ENDPOINT = 'https://script.google.com/macros/s/…/exec';
```

Vercel이 자동으로 다시 배포하면 바로 동작합니다. 휴대폰으로 `/newcomer`에 들어가 시험 신청을 한 번 해 보고, 시트에 한 줄이 생기는지와 메일이 오는지 확인하세요. 시험 행은 지워도 됩니다.

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다. **새 배포**를 누르면 URL이 바뀝니다.

## 시트 사용법

| 열 | 설명 |
|---|---|
| 신청일시 ~ 유입 | 자동 입력. `유입`이 `qr`이면 QR 코드로 들어온 신청입니다(`/newcomer?src=qr`) |
| **진행 상태** | 신청 → 연락함 → 1주차 → 2주차 → 3주차 → **성도 등록** / SC 연결 / 보류 |
| 담당 교역자, 메모 | 자유롭게 기록 |
| 파기 예정일 | 신청일 + 1년. 진행 상태가 **성도 등록**이 아니면 이 날짜가 지난 뒤 자동으로 삭제됩니다 |
| 알림 결과 | 메일·알림톡 발송 결과 |

- **성도 등록**한 분은 교적으로 옮긴 뒤 상태를 `성도 등록`으로 바꿔 주세요. 행이 초록색으로 바뀌고 자동 파기 대상에서 빠집니다.
- 시트 공유는 꼭 필요한 교역자에게만 하세요. 개인정보가 들어 있습니다.

## (3단계) 알림톡 붙이기

교회 측 준비가 끝나면 스크립트 속성만 추가하면 됩니다. 코드는 고치지 않아도 됩니다. 속성 중 하나라도 비어 있으면 알림톡은 보내지 않고 이메일만 보냅니다.

### 준비
1. 카카오톡 채널 개설 → **비즈니스 인증**(교회 고유번호증)
2. [솔라피](https://solapi.com) 가입 → 충전 → **카카오 채널 연동**으로 발신 프로필(pfId)을 발급받습니다
3. 알림톡 템플릿 2개를 심사 신청합니다(영업일 1~3일). 변수 이름은 아래와 **정확히 같아야** 합니다.

**교역자용 (`TPL_STAFF`)**
```
[움직이는교회] 새이웃 신청 알림

새이웃 만남 참여 신청이 접수되었습니다.
이름: #{이름}
연락처: #{연락처}
참여 희망: #{참여희망}
```

**신청자용 (`TPL_WELCOME`)**
```
[움직이는교회]
#{이름}님, 새이웃 만남에 참여해 주셔서 감사합니다.

앞으로 담당 교역자와 3주 동안 서로를 알아가는 시간을 갖게 됩니다.
곧 카카오톡 또는 문자로 일정과 장소를 안내해 드리겠습니다.
```

### 스크립트 속성 추가
| 키 | 값 |
|---|---|
| `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` | 솔라피 → 개발/연동 → API Key |
| `SOLAPI_PF_ID` | 발신 프로필 ID |
| `SOLAPI_FROM` | (선택) 솔라피에 등록한 발신번호 |
| `STAFF_PHONE` | 교역자 알림을 받을 휴대폰 번호 |
| `TPL_STAFF` / `TPL_WELCOME` | 승인된 템플릿 ID |

알림톡 발송에 실패해도(카카오톡 미사용자 등) 문자로 대신 보내지 않습니다. 결과는 시트의 `알림 결과` 열에 남습니다.
