## 1. 목표와 범위

- 기획안 Ⅲ장의 절차 중 **"1. 참여 신청"** 단계를 웹으로 구현합니다.
  `첫 방문 → [참여 신청] → 환영 연락 → 3주 만남 → 성도 등록 안내 → SC 연결`
- **이번 페이지는 참여 신청만 받습니다.** 성도 등록(생년월일·주소·세례·혼인 여부 등)은 받지 않습니다.
  기획안의 원칙: *"불필요한 항목은 최초 참여 단계에서 요청하지 않습니다."* / *"교인 등록과 구분합니다."*
- 명칭: 새가족은 **뉴패밀리**(표지 제목은 NEW FAMILY), 새가족반(3주 만남)은 **Family Table**(영문 표기, 2026-11-28 변경).
- 주소: `https://moving-village.vercel.app/newcomer` (같은 레포, 같은 Vercel 프로젝트)

## 3. 페이지 구성 (기획안 Ⅳ장 참여 카드 4쪽 → 웹)

성도 작정서처럼 **한 장씩 넘겨 읽습니다**(2026-11-27 변경). 하단 고정 이전/다음 버튼, 러닝헤드에 장 이름과 쪽수(1~3), 휴대폰 뒤로 가기는 이전 장. 제출 뒤에는 양식으로 돌아가지 않습니다. 모바일(QR 접속)이 기본입니다.

1. **환영** (카드 1쪽)
   - 제목: "뉴패밀리 여러분, 환영합니다."
   - 본문: 기획안 1쪽 환영 문구 그대로
2. **움직이는교회 소개** (카드 2쪽, 짧게)
   - "[ 살아나서, 살려내는 공동체 ]", 김포 운양동 Moving Village 소개(메인 사이트 문구 재사용)
   - 예배 안내 / SC 소개 / 공식 DNA·비전 → **`<!-- TODO: 담당 교역자 확인 -->` 자리 표시**
3. **뉴패밀리 테이블 3주 미리보기** (기획안 Ⅴ장)
   - 1주 **환영하다** "당신을 만나 반갑습니다." · 2주 **알아가다** "움직이는교회의 DNA를 소개합니다." · 3주 **연결되다** "이제 함께 걸어갑니다."
   - 회당 40~60분이며 일정은 참여자 상황에 맞춘다는 안내
   - **"3주 참여가 자동 등록을 의미하지 않습니다"** 문구를 눈에 띄게 둡니다 (부담 줄이기)
4. **참여 카드 (신청 양식)** (카드 3쪽)
5. **완료 화면** (카드 4쪽): 제출하면 양식 자리에 마무리 인사 문구가 나옵니다.
6. 하단: 문의 · 조관준 목사 · 010-2855-4091 / 메인 사이트로 가는 링크

## 4. 신청 양식

### 필수
| 필드 | 형식 | 비고 |
|---|---|---|
| 이름 | 텍스트 | |
| 연락처 | 휴대폰 번호 | `010-0000-0000` 형식 자동 정리, 숫자 키패드 |
| 개인정보 수집·이용 및 연락 동의 | 체크박스 | 체크하지 않으면 제출 버튼이 비활성화됩니다 |

### 선택 — "조금 더 알려주세요" (접혀 있음)
| 필드 | 형식 | 선택지 |
|---|---|---|
| 선호 연락 방법 | 선택 | 카카오톡 / 문자 / 전화 |
| 연락 가능 시간 | 선택 | 평일 낮 / 평일 저녁 / 주말 / 상관없음 |
| 뉴패밀리 테이블 참여 희망 | 선택 | 참여하고 싶어요 / 조금 더 생각해 볼게요 |
| 교회를 알게 된 경로 | 선택 | 지인 소개 / 인터넷 검색·SNS / 지나가다 / 기타 |
| 출생 연도 | 숫자 4자리 | 예: 1990. 적으면 1920년~올해만 허용(페이지·서버 모두 검사). 2026-11-28 연령대 선택지에서 변경 |
| 함께 온 가족·동반인 | 짧은 텍스트 | 예: "배우자, 자녀 2명" |
| 교회에 기대하거나 궁금한 점 | 긴 텍스트 | 1주차 대화의 소재로 씁니다 |

### 개인정보 동의 문구 (초안)
> **수집 목적** 뉴패밀리 테이블 안내 및 담당 교역자 연락
> **수집 항목** 이름, 연락처 (선택 항목: 연락 방법·시간, 알게 된 경로, 출생 연도, 동반인, 기대하는 점)
> **보유 기간** 성도 등록 시 교적으로 이관하며, 등록하지 않으면 신청일로부터 1년 후 파기합니다.
> **문의** 조관준 목사 010-2855-4091
> 동의하지 않을 수 있으나, 동의하지 않으면 뉴패밀리 테이블 안내를 받을 수 없습니다.

### 오용 방지
- 허니팟(숨김 필드)으로 스팸 봇 차단, 제출 중 버튼 잠금(중복 제출 방지)
- 서버(Apps Script)에서도 필수값과 전화번호 형식을 다시 검증

## 5. 기술 구조

```
[QR / 링크]
    ↓
moving-village.vercel.app/newcomer   (정적 HTML: newcomer/index.html)
    ↓  fetch POST (text/plain JSON — CORS 사전요청 회피)
Google Apps Script 웹앱 (doPost)
    ├─ 시트에 한 줄 추가
    ├─ 교역자 이메일 알림        ← 1차
    └─ 알림톡 발송 (솔라피 API)  ← 2차 (설정값이 있을 때만 동작)
```

- **프런트엔드**: 빌드 도구 없는 단일 HTML. 메인 `index.html`과 같은 방식이고 Noto Sans KR을 씁니다.
  - 파일: `newcomer/index.html` (Vercel은 `/newcomer` 요청에 이 파일을 내려줍니다)
  - 웹앱 URL은 HTML 안에 상수로 둡니다(공개되어도 괜찮은 값).
- **백엔드**: `apps-script/Code.gs` 를 레포에 보관하고, 시트의 확장 프로그램 → Apps Script에 붙여 넣어 배포합니다.
  - 솔라피 API 키·발신 프로필 ID·템플릿 ID는 **스크립트 속성**에 저장하고 레포에는 올리지 않습니다.
  - 키가 비어 있으면 알림톡 단계를 건너뜁니다. 그래서 알림톡이 준비되기 전에도 그대로 운영할 수 있습니다.
- **파기 자동화**: 매일 도는 시간 트리거가 `상태 ≠ 성도 등록` 이고 신청일이 1년을 넘은 행을 삭제합니다.

### 시트 열 구성
| 열 | 입력 주체 |
|---|---|
| 신청일시, 이름, 연락처, 선호 연락 방법, 연락 가능 시간, 참여 희망, 알게 된 경로, 출생 연도, 동반인, 기대·궁금한 점, 동의 일시 | 자동 |
| **진행 상태**: 신청 → 연락함 → 1주차 → 2주차 → 3주차 → 성도 등록 / SC 연결 / 보류 (드롭다운) | 교역자 |
| 담당 교역자, 메모 | 교역자 |
| 파기 예정일 (= 신청일 + 1년, 수식) | 자동 |
| 알림톡 발송 결과 | 자동 |

## 6. 디자인 방향 — 성도 작정서와 같은 디자인 시스템 (2026-11-27 변경)

- 기준: `movingchurch-web/commit.html`(movingchurch.kr/commit). 토큰을 그대로 옮겼습니다.
  - 흰 종이 `#FFFFFF`, 표지 크라프트 `#D6D3C4`, 먹 `#141A1E`, 헤어라인 `#D9D6CC`
  - 물 청록 `#18A8C8`/`#0E7390`(읽기 구간), 씨앗 올리브 `#6A7A32`/`#586828`(참여 카드·제출)
- 글꼴은 Pretendard 하나. 명조·라운드 카드·알약 칩·원형 숫자·그림자 없음
- 상자 대신 헤어라인과 굵기로 위계. 입력은 밑줄형, 선택지는 네모 체크
- 러닝헤드(로고 + 진행선), 크라프트 표지, 화면 폭 사진(운양동 현장, `newcomer/img/`)
- 처음 계획의 "크림 + 블루" 따뜻한 톤은 폐기

## 7. 작업 단계

### 1단계 — 페이지 + 시트 + 이메일 (바로 진행 가능)
1. `newcomer/index.html` 제작: 환영 / 소개 / 3주 미리보기 / 양식 / 완료 화면
2. `apps-script/Code.gs` 작성: 저장, 검증, 교역자 이메일 알림, 1년 파기 트리거
3. 시트 템플릿: 열 구성, 상태 드롭다운, 파기 예정일 수식
4. 배포 가이드 `docs/newcomer-setup.md`: 시트 만들기 → 스크립트 붙여 넣기 → 웹앱 배포 → URL 넣기
5. 메인 사이트에서 연결할지 결정 (아래 미결 사항)
6. 모바일 실기기 확인: iOS Safari, 안드로이드 크롬, 카카오톡 인앱 브라우저

### 2단계 — 인쇄물
7. QR 코드 생성 (`/newcomer?src=qr` 처럼 경로를 구분해 유입을 집계)
8. 인쇄용 QR 카드(명함 크기)와 A4 포스터를 PDF로 제작 — 따뜻한 환대 톤에 맞춤

### 3단계 — 알림톡 (교회 측 준비 후)
9. 교회 측: 카카오톡 채널 개설 → 고유번호증으로 비즈니스 인증 → 솔라피 가입·충전 → 발신 프로필 연동
10. 템플릿 2종 심사 신청 (영업일 1~3일)
    - **교역자용** "뉴패밀리 신청이 접수되었습니다. #{이름} / #{연락처} / 참여 희망: #{참여희망}"
    - **신청자용** "#{이름}님, 뉴패밀리 테이블에 참여해 주셔서 감사합니다. 담당 교역자가 곧 일정과 장소를 안내해 드리겠습니다." (기획안 4쪽 마무리 인사 요약)
11. 스크립트 속성에 키 입력 → 테스트 발송 → 이메일 알림은 유지할지 끌지 결정
